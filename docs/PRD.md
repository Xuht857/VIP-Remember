# 会员记录 APP · 产品需求文档（PRD）

> 版本：v1.0（MVP 定稿） · 日期：2026-11-03
> 工作名：`member_vault`（正式名待定，可替换）
> 开源协议：MIT · 形态：Flutter APP（Android + iOS） · 数据：本地优先

---

## 1. 产品定位

**一句话**：记住"我在哪些 APP 有会员、什么等级、几时到期、有没有自动续费"的手机备忘录。

### 1.1 解决的痛点

用户（本人及同类人群）在网易云音乐、京东、淘宝、百度网盘、哔哩哔哩等大量 APP 开通了会员，但：

- 不记得自己开了哪些会员、什么等级；
- 不记得什么时候到期，容易"被自动续费"扣款；
- 想取消自动续费时找不到入口、想不起来是哪几个。

### 1.2 与"订阅记账工具"的差异

| 维度 | 本产品 | Wallos / SubTrack 类订阅记账工具 |
|---|---|---|
| 核心问题 | **我有哪些会员、几时到期、是否自动续费** | 我每月花多少钱 |
| 核心对象 | 会员状态（等级/到期/自动续费） | 订阅账单（金额/周期） |
| 金额字段 | 选填 | 必填核心 |
| 到期提醒 | 系统本地推送（核心能力） | 邮件/IM 通知（需服务器） |
| 数据 | 本地 SQLite，离线可用 | 服务端数据库 |

### 1.3 目标用户

- 在多个 APP 开通会员、被自动续费困扰的个人用户；
- 希望随手记录、到期前被提醒的手机重度用户；
- 关注数据隐私、不希望上传云端的用户。

## 2. 关键决策记录（讨论定稿）

| # | 决策点 | 结论 | 备注 |
|---|---|---|---|
| 1 | 会员数据来源 | **纯手动录入**，UI 滑动开关简化 | 自动查询各 APP 会员无数据通路（各平台无统一查询枢纽，类"云闪付查卡"机制不存在），已论证放弃 |
| 2 | 底座 | **从零自研（clean-room）** | SubTrack 无开源协议（license: null），不可二开后开源；仅借鉴其产品设计思路 |
| 3 | Top100 充值榜单 | **放弃** | 原诉求"了解市场热门 APP 以便针对性开发接口"由内置应用目录承接 |
| 4 | 产品形态 | **Flutter APP** | 系统级本地推送可靠、离线可用、GitHub 受众大 |
| 5 | 开源协议 | **MIT** | 传播最友好 |
| 6 | 数据存储 | **本地 SQLite 优先** | 免服务器、隐私最佳；云同步二期 |
| 7 | 登录 | 仅作数据归属/备份恢复标识 | **不做**跨平台会员匹配（技术不可行） |

## 3. 功能需求

### 3.1 P1 · MVP（本期实现）

| 编号 | 功能 | 说明 |
|---|---|---|
| F1 | 会员记录 CRUD | 添加、查看、编辑、删除；一条记录 = 一个 APP 的会员状态 |
| F2 | 内置应用目录 | 预置主流 APP（购物/音视频/网盘/游戏/办公等分类），点选即填名称与图标；支持自定义应用 |
| F3 | 会员状态字段 | 是否开通（滑动开关）、会员等级（文本，如"黑金VIP"）、到期日、是否自动续费（滑动开关） |
| F4 | 横条列表 | 每行一个应用：`[图标] 名称 · 等级 · 到期日 · [自动续费徽标]`，支持按到期日排序/筛选 |
| F5 | 到期提醒 | 系统本地推送，默认到期前 3 天提醒，天数可全局配置 |
| F6 | 极简录入 | 选应用 → 选到期日 → 两个滑动开关 → 完成；金额/备注等全部选填折叠 |

### 3.2 P2 · 二期

| 编号 | 功能 | 说明 |
|---|---|---|
| F7 | 多登录账号 | 一个用户可维护多个手机号/账号标签；每条会员可关联"该会员用哪个账号开的"，默认当前账号 |
| F8 | 云同步/备份 | WebDAV 或自选云盘备份；换机迁移 |
| F9 | 统计视图 | 按分类/到期时间分布、自动续费总览 |
| F10 | 微信小程序版 | 复用数据模型，拓展使用场景 |
| F11 | CSV/JSON 导入导出 | 数据可携带 |

### 3.3 明确不做（Non-goals）

- ❌ **手机号一键匹配各平台会员**：各 APP 无统一会员查询枢纽（对比：银行卡有银联 Findcard 接口，APP 会员没有对等基础设施），技术不可行；
- ❌ **保存各 APP 账号密码自动抓取会员页**：违反平台 ToS、需托管凭证、维护脆弱，安全风险不可接受；
- ❌ **充值费用排名 Top100 榜单**：依赖跨平台接口聚合，前提不成立；
- ❌ 代扣/退订自动化操作：只做"记录与提醒"，不做任何支付操作。

## 4. 数据模型（本地 SQLite）

```
Account（登录账号）                    MemberRecord（会员记录）
├─ id            INTEGER PK          ├─ id             INTEGER PK
├─ label         TEXT  昵称           ├─ appName        TEXT    应用名
├─ identifier    TEXT  手机号/邮箱     ├─ appIcon        TEXT?   图标路径/URL
├─ type          TEXT  phone/email/…  ├─ category       TEXT?   分类
└─ isDefault     INTEGER (0/1)       ├─ level          TEXT?   会员等级
                                     ├─ expiresAt      TEXT?   到期日 YYYY-MM-DD
                                     ├─ autoRenew      INTEGER (0/1)  自动续费
                                     ├─ isActive       INTEGER (0/1)  是否开通
                                     ├─ accountId      INTEGER? FK→Account
                                     ├─ price         REAL?   年费/月费（选填）
                                     ├─ notes          TEXT?   备注
                                     ├─ createdAt      TEXT
                                     └─ updatedAt      TEXT

AppCatalog（内置目录，打包随 APP 发布）
├─ id / name / category / iconAsset / defaultLevel?
```

设计要点：
- 金额 `price` 选填——本产品核心是"状态"不是"账目"；
- `expiresAt` 允许为空（永久会员/记不清）；
- 软删除不引入，MVP 直接物理删除（本地数据，简单优先）。

## 5. 页面与交互流程

### 5.1 页面清单

| 页面 | 内容 |
|---|---|
| 首页（列表） | 横条列表 + 顶部筛选（全部/即将到期/自动续费中）+ 右下"+"添加 |
| 添加/编辑页 | 应用目录点选（分类 Tab + 搜索）→ 等级（可选）→ 到期日 → 两个滑动开关 → 折叠的选填区（金额/备注/账号） |
| 设置页 | 提醒提前天数、默认账号、数据导出（P2） |

### 5.2 极简录入流程（F6 核心）

```
点选应用（或自定义）→ 到期日 → [滑动]自动续费 → [滑动]是否开通 → 保存
```

- 仅"应用名"必填，其余全有默认值；
- 保存后直接回列表，横条立即可见。

### 5.3 横条视觉规格

```
┌────────────────────────────────────────────────┐
│ [图标] 网易云音乐  黑金VIP        2027-03-15到期 │
│        [自动续费]                  [编辑] [删除] │
└────────────────────────────────────────────────┘
```

- 到期 ≤7 天：到期日高亮警示色；
- 已过期：灰色 + "已过期"标记；
- 自动续费：徽标常显（提醒用户关注）。

## 7. 技术架构

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Flutter 3.x（stable） | 一套代码双端；本地推送生态成熟 |
| 本地库 | `sqflite`（+ `path`） | 轻量、无服务器、成熟稳定 |
| 状态管理 | `provider` 或原生 `ChangeNotifier` | MVP 够用，避免过度设计 |
| 本地推送 | `flutter_local_notifications` | 到期提醒核心能力，无需联网 |
| 日期 | `intl` | 格式化/中英文 |
| 图标 | 内置 assets + 字母头像兜底 | 不依赖在线图标 API（clearbit 已不可靠） |

代码结构：

```
lib/
├─ main.dart
├─ models/          # MemberRecord / Account / AppCatalogItem
├─ data/            # db_helper.dart / app_catalog.dart
├─ ui/
│  ├─ home/         # 列表页（横条）
│  ├─ edit/         # 添加/编辑页（滑动开关）
│  └─ settings/     # 设置页
└─ services/        # notification_service.dart
```

## 9. 验收标准（MVP）

1. 冷启动后 3 步内完成一条会员录入（选应用→到期日→保存）；
2. 列表横条正确显示图标、名称、等级、到期日、自动续费徽标；
3. 开启自动续费的记录在列表中可筛选出"自动续费中"；
4. 到期前 N 天收到系统本地通知（杀进程状态也能收到）；
5. 断网可用全部功能；
6. 无必填项超过 1 个字段的录入路径。
